## Prompting techniques

Specificity named operations, files, and expected behavior. Constraints supplied tenant-isolation, audit-immutability, and no-edit requirements. Decomposition separated domain, persistence, API, migration, and test work. Iterative refinement used build/test feedback and review findings. The Plan and `#file` entries above are examples to run, not historical usage; to meet a rubric requiring those features as completed usage, execute them and record the actual response.
